# 检索片段服务

本站文档站接入了一个**检索片段（snippet）服务**，支持对接口字段、接口名与错误码做带类型高亮的全文检索。后端服务代码位于仓库根目录的 `search-service/` 文件夹，零运行时依赖，可直接 `npm test` 运行其 38 项自动化测试。

::: tip 启动搜索 API
```bash
cd search-service
node src/server.js --port 5174
```
默认在演示数据上构建首个索引代次后对外提供 `/api/search`。内部文档需请求头 `x-principals: group:admin`。
:::

## 关键设计

### 偏移安全：规范化/分词偏移绝不直接当原文位置

检索文本经过 `HTML 剥离 → NFKC 规范化 + 小写` 两级视图变换，每一级都维护一张 `OffsetMap`：

- 索引/分词的位置始终是**某一视图的码点（code point）偏移**，绝不直接当作 JavaScript 的 UTF-16 下标或字节偏移；
- 所有切片都按码点进行，配合代理对检查，保证 emoji、中文等多字节文本不会被截坏；
- 片段展示文本取自**剥离标签后的纯文本视图**并再次 HTML 转义，原文中的 `<script>` 等永远不会被当标签执行。

### 两套分析规则

- **自然语言分析器**：NFKC + 小写、按非词字符切分，并对中日韩文字产出单字与相邻二元（bigram），无需词典即可检索中文；
- **代码标识符分析器**：保留完整标识符与点分路径，拆分 camelCase / snake_case / kebab-case，识别 `E4001`、`ERR_TIMEOUT`、`HTTP_404` 等错误码；单字母碎片（如 `E4001` 中的 `E`）不入库以避免噪声。

### 分版本索引与代次发布

- 搜索 API 读取**按版本解析的活动索引代次**；关系库保存文档、版本、章节、可见性与代次信息（见 `schema.sql`）。
- 索引**先在新代次完整构建，再原子切换**活动指针；构建期间旧索引继续服务。
- 只有**已发布版本**进入全文索引；草稿/未发布正文永不可被检索，元数据更新不会让结果指向未发布内容。
- 同一逻辑文档的历史版本被标记为 `historical`，默认只返回当前版本，可显式包含历史结果。

### 索引时权限 vs 查询时回查权限

- **索引时快照**仅作非权威提示（例如“构建时是否公开”），不用于安全决策；
- **查询时回查**关系库当前可见性是唯一权威闸门，每次检索都执行；
- **撤回立即过滤**：撤回后无需重建索引，结果立刻被过滤；后台清扫任务再异步物理删除倒排记录。

### 不把“未索引完成”冒充“无匹配”

- 构建中 / 已构建未发布 / 完全无索引分别返回 `503 not_ready`、`503 not_ready`、`503 no_index`；
- 只有索引就绪且确实无命中时才返回 `200` + `total: 0`；
- 恢复可见但尚未重建的文档会在 `indexCoverage.staleDocuments` 中标注，提示覆盖不完整。

### 旧游标翻页

分页使用带完整性签名的不透明键集游标。游标绑定**代次、查询词与版本过滤**；代次切换、查询变化、权限变化导致锚点失效，或游标损坏时，分别以 `410 STALE_CURSOR` / `400 INVALID_CURSOR` 明确拒绝，而不是混入新旧结果。
